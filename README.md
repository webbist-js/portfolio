# Portfolio

Personal portfolio — SvelteKit frontend + Strapi 5 backend, managed as an npm-workspaces
monorepo with Turborepo. Content model and visual design derived from the Claude Design
prototype (`Portfolio.html` / `directions/editorial.jsx`).

## Structure

- `backend/` — Strapi 5 (TypeScript, SQLite in dev)
- `frontend/` — SvelteKit (Svelte 5 runes, TypeScript), design-system components in
  `src/lib/components/`, tokens in `src/lib/styles/`

## Getting started

```sh
npm install            # installs all workspaces

npm run seed           # one-time: seed prototype content (backend stopped)
npm run dev            # starts backend (:1337) and frontend (:5173) via turbo
```

First backend boot: create an admin user at http://localhost:1337/admin.
Public `find`/`findOne` permissions are granted automatically on boot
(`backend/src/index.ts`), so the frontend needs no API token.

## Scripts (root)

| Script | What it does |
|---|---|
| `npm run dev` | Both dev servers via turbo |
| `npm run build` | Build all workspaces |
| `npm run lint` | Prettier check + ESLint |

| `npm run test:e2e` | Playwright e2e + axe accessibility suite (needs seeded backend on :1337) |

## Testing

- **Unit** (`frontend/src/**/*.test.ts`, Vitest): Strapi client behaviour with mocked fetch.
- **E2E** (`frontend/e2e/*.e2e.ts`, Playwright): route smoke tests against a production
  build + seeded CMS, keyboard navigation, and automated WCAG 2.2 AA scans on every page
  via `@axe-core/playwright`.
- **CI** (`.github/workflows/ci.yml`): lint → typecheck → unit → build on every push;
  a second job boots a seeded Strapi and runs the full e2e + a11y suite.

## Strapi MCP server

The backend exposes Strapi's built-in MCP server at `http://localhost:1337/mcp`
(streamable HTTP), enabled via `mcp.enabled` in `backend/config/server.ts`
(toggle with `MCP_ENABLED`). Authentication uses an **Admin token**; the token's
permissions decide which tools the AI client sees.

Mint / rotate the token (dev server stopped — prints the key once):

```sh
cd backend && node scripts/create-mcp-token.cjs
```

Connect a client (Claude Code):

```sh
claude mcp add strapi-local --transport http http://localhost:1337/mcp \
  --header "Authorization: Bearer <ACCESS_KEY>"
```

The current token grants content-manager CRUD (+publish where Draft & Publish is
enabled) across all app content types — ~87 tools (`list_project`, `create_article`,
`publish_service`, …).

## Forms & email

The contact form (About) and newsletter form (Writing) are SvelteKit form actions —
progressively enhanced, honeypot-protected, working without JavaScript. Submissions are
stored in Strapi (public role has `create` only; reads stay private) and an `afterCreate`
lifecycle emails a notification to `EMAIL_TO` via SendGrid.

To enable email, set in `backend/.env` (see `.env.example`):

```sh
SENDGRID_API_KEY=SG.xxxxx      # from app.sendgrid.com — sender must be verified
EMAIL_FROM=info@alex-bennett.co.uk
EMAIL_TO=info@alex-bennett.co.uk
```

With no key set (local dev), submissions still store and the skipped email is logged.

## Frontend

`frontend/src/lib/strapi.ts` is a typed client for the Strapi 5 REST API. Routes mirror
the prototype pages: `/`, `/work`, `/work/[slug]`, `/services`, `/writing`,
`/writing/[slug]`, `/about`. Set `PUBLIC_STRAPI_URL` in `frontend/.env` (defaults to
`http://localhost:1337`).
